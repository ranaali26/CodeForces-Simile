# \# CodeForces Simile

# 

# A tool to compare Codeforces profiles — see which problems your friend solved that you haven't, view statistics, and track progress.

# 

# \## Features

# \- Compare solved problems between two users

# \- View submission statistics per user

# \- Problem ratings distribution

# \- CLI and GUI interfaces

# 

# \## Setup

# ```bash

pip install -r requirements.txt
